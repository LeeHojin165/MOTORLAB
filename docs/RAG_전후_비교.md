# RAG 사용 전후 답변 품질 비교 (F2015)

## 1. 방법

| 항목 | 내용 |
|---|---|
| 실행일 | 2026-10-23 |
| 모델 | gpt-4o (두 방식 모두 같은 모델, temperature 0) |
| RAG 없이 | `NO_RAG` 프롬프트 — "자동차 전문가로서 5문장 이내로 답하라". 근거 문서 없음 |
| RAG | 서비스 경로 그대로 — 수집 → retrieve(메타데이터 1 + 문서 청크, 유사도 Top-6) → generate(프롬프트 3) |
| 실행 방법 | `chat_events(..., compare_rag=True)` — 화면 설정의 「RAG 전후 비교」와 같은 기능 |
| 원본 기록 | `evidence/17_rag_compare.json`, `evidence/17_rag_compare.txt` (스크립트 `evidence/scripts/verify_rag_compare.py`) |

**질문 선정 기준** — 근거 없이 답하면 틀리기 쉬운 질문 7개를 골랐습니다.
- 출시가 최근이라 모델 학습 데이터에 없거나 이전 세대와 헷갈리기 쉬운 차량 (2024 EV3, 2025 아이오닉 9, 2026 iX3)
- 자료가 적은 오래된 국산차 (1975 포니, 1991 티코)
- 색인 문서에 **없는** 정보 (로드스터 가격, 토레스 EVX 배터리 제조사) — 모르는 것을 모른다고 답하는지 확인

**채점 기준** — 사실 정확성은 색인된 근거(차량 메타데이터 · 위키백과 문서)의 값과 대조했습니다. 색인 문서에 정보가 없어 대조할 수 없는 경우는 「검증 불가」로 따로 표시했습니다.

## 3. 종합

| 기준 | RAG 없이 | RAG |
|---|---|---|
| **사실 정확성** (Q1~Q5, 근거로 대조 가능한 수치 10개) | 정확 3 · 근사 1 · 틀림 6 | 정확 10 · 틀림 0 |
| **근거 제시** (7문항) | 0 / 7 — 출처를 하나도 대지 못함 | 답한 6문항 모두 [근거 n]과 원문 출처 제시, 답하지 못한 1문항은 근거 없음을 안내 |
| **모르는 것을 모른다고 답함** (색인에 없는 정보 2개: Q6 가격, Q7 제조사) | 0 / 2 — 둘 다 값을 단정 | 2 / 2 — 둘 다 "확인되지 않습니다" |
| 처리 시간 (RAG 쪽, 수집 포함) | — | 2.6 ~ 14.0초 |

### 관찰

1. **신형 차량일수록 RAG 없는 답이 크게 틀렸습니다.** EV3 · iX3는 두 수치가 모두 틀렸고, 이전 세대나 다른 차급의 값을 가져온 것으로 보입니다. "예상됩니다", "공식 자료를 참고하세요" 같은 표현을 붙이지만, 틀린 숫자는 그대로 남습니다.
2. **맞는 값과 틀린 값이 한 답변 안에 섞입니다.** 포니(배기량 ✅ · 출력 ❌), 아이오닉 9(토크 ✅ · 가속 ❌)처럼 일부만 틀리면, 출처가 없어서 사용자가 어느 쪽이 틀렸는지 가려낼 수 없습니다.
3. **RAG는 근거끼리 값이 다를 때 그 차이를 드러냅니다.** 포니의 출력은 메타데이터(80 PS)와 영문 위키(55 PS)의 값이 다른데, RAG 답변은 두 값을 모두 출처와 함께 보여 줍니다. RAG 없는 답은 어느 근거에도 없는 68 PS를 단정했습니다.
4. **RAG의 한계는 색인 범위입니다.** 로드스터 가격 · 토레스 EVX 배터리 제조사처럼 색인 문서에 없는 정보는 답하지 못합니다. 서비스는 이것을 추측으로 메우지 않고 "확인되지 않습니다"로 답하도록 설계했으며, 이번 비교에서 그대로 동작했습니다. 이 범위를 넓히는 것은 수집(프롬프트 1·2)의 몫입니다.
5. RAG 쪽 정확성은 **색인된 근거가 정확하다는 전제** 위에 있습니다. 메타데이터는 직접 정리한 값이라, 영문 위키 인포박스와 자동 대조한 결과를 `data/verify_report.md`에 남겼습니다.
